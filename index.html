Start free, on your own machine

The local CLI is the front door: install it, point it at a folder of assets, and get certificates + auto-healed .glb files. No account, no upload, no key — it runs entirely offline.

copy# install the free local CLI ($0, offline, free-use license — see LICENSE)
pip install "3dqa[repair,fast]"

# audit a single asset — exit code doubles as a CI gate (0=PASS, 1=FAIL)
3dqa lint model.glb --pretty

# auto-heal every failing asset in a folder, writing *_repaired.glb
3dqa heal ./exports --targets unity_mobile,three_js_web

# gate a whole batch and print a per-target compatibility table
3dqa lint ./exports --config 3dqa.config.json

Everything the dashboard and API do, on the command line — same deterministic core, same certificates. Upgrade to the hosted API and the GitHub gatekeeper when you want to enforce QA across a team.
